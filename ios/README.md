# 墨夜阅读器 iOS / iPadOS 3.5.14

3.5.14 修复连续打开作品时，旧页面的退出操作误取消新作品请求的问题；不同作品使用独立的页面状态。长条滚动修复、双页操作、封面加载及当前章 / 下一章预加载行为沿用 3.5.13。

适用于 iPhone 和 iPad，iOS / iPadOS 17 或以上。

此版保留 Mac 3.5.9 的章节、阅读与下载规则，并按新的要求调整移动版首页和双页操作：

- 无需账号。所有站点请求共用本次运行的匿名 Cookie，不读取旧版账号会话。
- 首页只保留每月热看，支持观看数 / 点赞数排序。移除固定底部翻页栏，滑到列表末尾自动加载后续作品；重叠作品去重，没有新作品时停止加载。右上角直接选择 1、2、3 列，始终按所选列数显示并记住选择。
- 作品卡片左侧显示完整竖版封面，右侧显示标题、作者、分类和编号。封面按原比例缩放，避免填满横向区域造成裁剪。窄卡片省略作者、分类等介绍，保留完整封面与简短标题。可见封面优先加载，并使用独立的缩略图缓存；离开可见区域后取消无用请求。
- 搜索、详情与章节使用和 Mac 相同的解析与作品信息规则。后台网页只解析内容，拦截图片、媒体和远程字体，避免和原生界面重复下载。打开作品会优先结束首页续载，复用已启动的解析引擎；下一章节预加载使用独立解析请求。
- 单话作品直接进入阅读；多话作品停留在选话界面。返回选话页时不重复自动进入阅读。
- 横向双页没有中缝，单独一页居中。点左侧进入下一组：整体画面向右移动，新图片从左侧进入；点右侧返回上一组，反向移动。向右轻扫同样进入下一组。动画可被后续操作立即打断，不再等待固定时长；直接移动已有页面视图，避免整屏截图和同步绘制。长条页仍可上下拖动查看完整内容。
- 点击中间区域时工具栏淡入淡出，阅读画布保持固定，避免反复缩放和重绘。画面、图片和提示均未变化时跳过重复绘制。
- 只保留横向双页和长条漫画两种模式。长条模式支持无缝连续浏览和按屏滚动；切换模式、旋转屏幕、图片尺寸加载后保留阅读位置。旧版竖向阅读设置会转为长条漫画。
- 打开章节后，预加载当前章节与下一章节的全部原图；不遍历其余章节。切换章节后更新范围。当前可见页优先，后台预加载最多同时请求两张，为阅读保留请求容量。压缩原图写入本次运行的临时缓存，只解码可见页和附近少量页面；超长页只绘制屏幕附近的内容。解码缓存进入后台后释放，预加载的原图仍可复用；手动清缓存会同时停止预加载并清除临时文件。
- 阅读与下载使用独立请求，避免互相取消。ZIP 按作品名保存，页面按章节和页码命名，保留原始分辨率；无需恢复的图片保留原文件，必要时恢复图片后保存为 PNG 或高质量 JPEG。

## 构建

需要完整 Xcode 和 iOS SDK：

```sh
./ios/build_ipa.sh
```

生成 `outputs/MoyeReader-iOS-iPadOS-3.5.14-unsigned.ipa`。与原安装包一样，这是未签名 IPA，需要通过原先使用的签名 / 安装工具签名后安装。构建没有包含开发者证书、账号、Cookie、个人设置或阅读缓存。

本地模拟站点与模拟器检查：

```sh
python3 tests/run_ios_smoke.py
```

检查 iPhone 和 iPad 上的章节流程、提前解析、每月榜单和排序、连续加载与去重、80 部作品时的按需加载、实际 1–3 列卡片布局及完整封面、匿名 Cookie、下载 ZIP、双页贴合、实际动画方向、快速连续输入、中间点击时画布稳定、当前与下一章节完整预加载、长图滚动和阅读位置。测试输出到 `outputs/ios-verification/`。

本地封面批量加载和连续翻页基准：

```sh
MOYE_PERFORMANCE=1 MOYE_TEST_OUTPUT=ios-performance python3 tests/run_ios_smoke.py
```

基准使用固定本地图片和网络延迟，不能代表实际站点网速或真机帧率。
