# 墨夜阅读器

原生 macOS 漫画阅读器，当前版本 **3.5.9**。

## 运行

双击 `outputs/墨夜阅读器.app`。

适用于 Apple 芯片 Mac，macOS 26 或以上。

## 编译

需要 macOS 26 SDK 和 Swift 编译器（Xcode 或 Command Line Tools）。

在项目目录执行：

```sh
./build.sh
```

构建完成后生成 `outputs/墨夜阅读器.app`，使用本机临时签名；构建缓存自动清理。重新编译会替换该目录中的已有 APP，请先退出正在运行的版本。

也可以指定输出目录：

```sh
./build.sh /path/to/output
```

生成 DMG 安装包：

```sh
./package.sh
```

无需外部站点的匿名使用回归检查：

```sh
python3 tests/run_no_account_smoke.py
python3 tests/run_reader_layout_smoke.py
```

该检查使用独立测试程序和本地模拟站点，验证搜索、单话自动阅读、多话停留选话、指定章节阅读、章节下载、匿名 Cookie 共享及 ZIP 内容。
阅读器检查另用合成图片验证双页贴合、超长图比例、可见区域绘制、阅读位置保持和章末滚动，并输出测试画面。

## iOS / iPadOS

`ios/` 包含 **3.5.16** 版，支持 iPhone / iPad 和 iOS / iPadOS 17 或以上。作品信息规则、单话直读 / 多话选话及下载规则与 Mac 版同步。移动版首页只保留每月热看，右上角直接选择 1、2、3 列；封面保持原比例填充并裁剪，阅读后不会变为章节缩略图，窄卡片精简简介。支持本机收藏，首页“我的收藏”使用相同卡片与列数。接近列表末尾时继续加载，移除固定底部翻页栏。阅读方式只保留横向双页和长条漫画，点左侧时下一组从左侧进入、整幅画面向右移动；支持连续操作打断动画。当前章节和下一章节的全部原图在后台预加载，可见页优先；中间点击只切换工具栏，保持阅读画布稳定。

使用完整 Xcode 编译未签名 IPA：

```sh
./ios/build_ipa.sh
```

运行 iPad 模拟器与本地站点检查（需要完整 Xcode 和已安装的 iOS 模拟器）：

```sh
python3 tests/run_ios_smoke.py
```

功能及安装说明见 `ios/README.md`。IPA 与原版一样需要签名后安装。

## 目录

- `source/Sources/`：Swift 源码。
- `source/Assets/`：图标、插图及第三方声明。
- `source/Info.plist`：应用配置。
- `build.sh`：编译及打包脚本。
- `package.sh`：生成附带安装说明的 DMG。
- `tests/`：匿名使用回归检查。
- `ios/`：iOS / iPadOS 源码、Xcode 工程和 IPA 构建脚本。
- `outputs/墨夜阅读器.app`：完成的应用。

## 首次使用

1. 安装后打开 APP，首页即可搜索、阅读和下载公开作品。
2. 首页右上角可选择站点线路，以及切换浅色/深色模式。
3. 3.5.6 已移除登录按钮、账号窗口和登录会话保存、恢复功能；打开即可使用。

## 使用

- 支持作品名、作者名和 JM 编号搜索。点击作品卡片时，只有一话的作品直接阅读；多话作品停留在选话界面，点击章节后开始阅读。
- 支持浅色/深色、1–3 列、无中缝双页、竖向阅读和无缝长条漫画阅读。
- 横向双页遇到长条页时仍保持两页并排，按列宽显示原始比例；可上下滚动查看完整长页，读到底后再翻下一组。普通页继续整页适配，普通页和长页混排时各自保持比例。
- 长条模式按窗口宽度显示完整长图，只绘制屏幕附近的内容。图片加载、窗口缩放及模式切换时保留阅读位置；空格、Page Down/Up 和底部按钮按屏滚动，读完最后一页后才进入下一章。
- 阅读器按 `V` 切换模式，按 `F` 全屏；隐藏工具栏后单击画面可暂时唤出。
- 多章节作品在阅读器底部提供“下一章 / 上一章”和当前章节信息。按 `N` 或 `⌥←` 进入下一章，按 `P` 或 `⌥→` 返回上一章；到章末继续向前翻页即可进入下一章。切换章节保留阅读模式与工具栏显示设置，优先使用本次运行中已加载的章节。
- 下载时选择章节，进度窗口可取消下载；完成的 ZIP 按作品名称命名。
- ZIP 只包含所选章节的页面图片。无需恢复的图片保留原文件；需要恢复的 JPEG，以及无透明内容的 WebP/AVIF/HEIF 页面，保持原始分辨率，按 95% 质量保存为 JPEG（若 PNG 更小则保留 PNG）。PNG 和透明页面保留无损格式。不会将阅读缓存、封面或 APP 资源一起打包。
- 阅读缓存保留至退出软件。站点匿名 Cookie 只在本次运行期间共享，退出后不保存，也不读取旧版保存的账号会话。

第三方参考及许可声明见 `source/Assets/ThirdPartyNotices.txt`，该文件同时打包在 APP 中。
