# 墨夜阅读器

Mac 端原生 JM（禁漫）漫画阅读与下载器，另提供 iPadOS 移植版 IPA，当前版本 **3.5.5**。项目全程由 ChatGPT 制作；作者编程基础有限，欢迎友善指教（请轻喷）。

## 下载

在 GitHub Releases 下载对应版本：

- **macOS**：`MoyeReader-3.5.5-macOS-arm64.dmg`，适用于 Apple 芯片及 macOS 26 或以上。
- **iPadOS**：`MoyeReader-iPadOS-3.5.5-unsigned.ipa`，未签名；需要自行签名后侧载。此构建最低支持 iOS/iPadOS 17。

## 源码包与运行

本包只包含源码、必需资源和编译脚本，不包含个人账号、密码、Cookie、登录会话、设置或阅读缓存。

解压后先按下方说明编译，再双击生成的 `outputs/墨夜阅读器.app`。

适用于 Apple 芯片 Mac，macOS 26 或以上。

## 编译

需要 macOS 26 SDK 和 Swift 编译器（Xcode 或 Command Line Tools）。

在项目目录执行：

```sh
./build.sh
```

构建完成后生成 `outputs/墨夜阅读器.app`，使用本机临时签名；构建缓存自动清理。重新编译会替换该目录中的已有 APP，请先退出正在运行的版本。

也可以指定输出目录：

```sh
./build.sh /path/to/output
```

## 目录

- `source/Sources/`：Swift 源码。
- `source/Assets/`：图标、账号界面插图及第三方声明。
- `source/Info.plist`：应用配置。
- `build.sh`：编译及打包脚本。
- `outputs/墨夜阅读器.app`：编译后生成的应用（源码包中不包含）。

## 首次使用

1. 安装后打开 APP，首页即可搜索、阅读和下载公开作品。
2. 点击“登录账号”，用户名和密码均为空，输入你自己的账号后提交。
3. 网站确认成功后显示“已成功登录”；退出后只保存自己的登录会话，不保存密码。
4. 再次打开时，已保存会话在后台检查，不会锁住登录入口。失效后可以重新登录。

## 隐私与本地数据

这个源码包不含开发者的真实账号、密码、登录 Cookie、登录会话、个人目录路径或设备序列号。软件运行后，登录用户名会保存在 macOS 用户偏好中，网站会话 Cookie 会保存在本机的 `~/Library/Application Support/MoyeShelf/SiteSessions/`；阅读偏好和下载目录也会由 macOS 保存在本机。这些数据由每位用户在自己电脑上使用软件时产生，不属于本仓库内容。

## 使用

- 支持作品名、作者名和 JM 编号搜索，点击整张卡片直接阅读。
- 支持浅色/深色、1–3 列、横向双页和竖向阅读。
- 阅读器按 `V` 切换模式，按 `F` 全屏；隐藏工具栏后单击画面可暂时唤出。
- 多章节作品在阅读器底部提供“下一章 / 上一章”和当前章节信息。按 `N` 或 `⌥←` 进入下一章，按 `P` 或 `⌥→` 返回上一章；到章末继续向前翻页即可进入下一章。切换章节保留阅读模式与工具栏显示设置，优先使用本次运行中已加载的章节。
- 下载时选择章节，进度窗口可取消下载；完成的 ZIP 按作品名称命名。
- ZIP 只包含所选章节的页面图片。无需恢复的图片保留原文件；需要恢复的 JPEG，以及无透明内容的 WebP/AVIF/HEIF 页面，保持原始分辨率，按 95% 质量保存为 JPEG（若 PNG 更小则保留 PNG）。PNG 和透明页面保留无损格式。不会将阅读缓存、封面或 APP 资源一起打包。
- 阅读缓存保留至退出软件，登录会话单独保存；项目文件中不包含账号或密码。
